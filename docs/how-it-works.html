How UnityUI Transformer Works

A 3-step compilation flow converting Figma design frames into native Unity UI Toolkit UXML & USS code.

Step 01

The Design Token

Paste your Figma design frame URL. The engine validates the strict node-id=... query parameter to target the exact UI component, preventing raw file link execution errors.

  • Strict URL node parameter validation guardrails
  • Direct Figma REST API node tree retrieval
  • Auto-Layout flex direction & bounding box extraction
Figma Node Inspector
// Input Figma URL Parameter
https://figma.com/design/Abc123Xyz/UI?node-id=102:405

"id": "102:405",
"name": "HUD_Inventory_Frame",
"layoutMode": "VERTICAL",
"itemSpacing": 12
Step 02

Secure Handshake

Authenticate seamlessly via official Figma OAuth 2.0 PKCE flow. Access tokens are encrypted locally using Windows DPAPI (ProtectedData), ensuring zero cloud footprint.

  • Local DPAPI Windows User-Scope Encryption
  • Automatic session persistence & hard disconnect purge
  • Live Figma profile handle & avatar synchronization
Windows DPAPI Vault (session.dat)
// DPAPI Local Encryption Engine
byte[] plainBytes = Encoding.UTF8.GetBytes(token);
byte[] encrypted = ProtectedData.Protect(
  plainBytes, Entropy, DataProtectionScope.CurrentUser
);

✓ Secure Local Session Initialized
Step 03

The Engine

The UxmlGenerator & UssGenerator engines translate Figma Auto-Layout flex direction, padding, gap, and text styles into clean, production-ready Unity UI Toolkit .uxml and .uss files.

  • Automated UXML tree node hierarchy generation
  • USS flexbox styling rules with custom class names
  • Live streaming log terminal output
Generated Unity UI Toolkit Assets
<ui:UXML xmlns:ui="UnityEngine.UIElements">
  <ui:VisualElement class="hud-inventory-frame"/>
</ui:UXML>

/* Generated USS Flexbox Styles */
.hud-inventory-frame {
  flex-direction: column;
  row-gap: 12px;
}
