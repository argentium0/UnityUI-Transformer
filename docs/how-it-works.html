How UnityUI Transformer Works

Explore the 3-step compilation flow converting Figma design frames into native Unity UI Toolkit UXML & USS assets.

Step 01: The Design Token

Paste your Figma design frame URL into the desktop application. The engine validates the strict node-id=... query parameter to target the exact UI component, preventing raw file link execution errors. 

// Input Figma URL Parameter
https://figma.com/design/Abc123Xyz/UI?node-id=102:405

// Figma REST API AST JSON Output
{
  "id": "102:405",
  "name": "HUD_Inventory_Frame",
  "type": "FRAME",
  "layoutMode": "VERTICAL",
  "itemSpacing": 12,
  "paddingLeft": 16,
  "paddingRight": 16
}

Step 02: Secure Handshake

Authenticate seamlessly via official Figma OAuth 2.0 PKCE flow. Access tokens and session credentials are encrypted locally using Windows Data Protection API (ProtectedData), ensuring zero cloud footprint. 

// DPAPI Local Encryption Engine (SecureStorageService.cs)
byte[] plainBytes = Encoding.UTF8.GetBytes(token);
byte[] encrypted = ProtectedData.Protect(
    plainBytes, 
    Entropy, 
    DataProtectionScope.CurrentUser
);
File.WriteAllBytes(filePath, encrypted);

// Status: Session stored safely at %LOCALAPPDATA%\UnityUITransformer\session.dat

Step 03: The Engine

The UxmlGenerator & UssGenerator engines translate Figma Auto-Layout flex direction, padding, gap, and text styles into clean, production-ready Unity UI Toolkit .uxml layout templates and .uss style sheets. 

<!-- Generated Unity UXML Layout Template -->
<ui:UXML xmlns:ui="UnityEngine.UIElements">
    <ui:VisualElement class="hud-inventory-frame">
        <ui:Label text="Inventory" class="hud-label" />
    </ui:VisualElement>
</ui:UXML>

/* Generated Unity USS Flexbox Style Sheet */
.hud-inventory-frame {
    flex-direction: column;
    row-gap: 12px;
    padding-left: 16px;
    padding-right: 16px;
}
